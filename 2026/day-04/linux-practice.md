# Day 04 - Linux Practice: Processes and Services

## Objective
Today I practiced Linux process management, systemd services, and basic troubleshooting using logs.

---

## 1. Process Commands

### Check Running Processes

```bash
ps aux
```

**Purpose:** Displays all running processes on the system.

### Monitor Processes in Real Time

```bash
top
```

**Purpose:** Shows CPU, memory, and process usage in real time.

---

## 2. Service Commands

### Check Nginx Service Status

```bash
systemctl status nginx
```

**Purpose:** Displays current status of the Nginx service.

### List Running Services

```bash
systemctl list-units --type=service --state=running
```

**Purpose:** Lists all currently running services.

---

## 3. Log Commands

### View Nginx Logs

```bash
journalctl -u nginx
```

**Purpose:** Displays logs generated by the Nginx service.

### View Last 50 Log Entries

```bash
journalctl -u nginx -n 50
```

**Purpose:** Shows the most recent 50 log entries.

---

## Service Inspection

### Service Name

Nginx

### Command Used

```bash
systemctl status nginx
```

### What I Learned

- Nginx runs as a systemd service.
- systemctl helps manage and monitor services.
- journalctl helps troubleshoot service issues.
- Logs provide useful information when a service fails to start.

---

## Small Troubleshooting Flow

### Problem

Nginx configuration error prevented the service from starting.

### Step 1 - Test Configuration

```bash
sudo nginx -t
```

### Step 2 - Review Logs

```bash
journalctl -u nginx -n 50
```

### Step 3 - Fix Configuration

Corrected the syntax error in the Nginx configuration file.

### Step 4 - Restart Service

```bash
sudo systemctl restart nginx
```

### Step 5 - Verify Status

```bash
systemctl status nginx
```

Result: Nginx started successfully.
